Primera versión etiquetada de la base. **No es una versión final**: sirve como punto de partida para empezar proyectos mientras el desarrollo continúa, y puede cambiar entre versiones `0.x`.

[English](https://github.com/VictorDiazJauregui/django-saas-base/blob/v0.2.1/docs/releases/RELEASE-v0.1.0.md)

### Incluye

- PostgreSQL 18 con Docker Compose, configurado por variables para que varios proyectos convivan en la misma máquina.
- Django 5.2 LTS y Django REST Framework, con autenticación JWT y auditoría de peticiones.
- Panel de administración con gestión de usuarios.
- Dependencias con `uv` y `requirements.txt` para `pip`.
- Guía de instalación para Linux, WSL y Windows.

### Requisitos

Python 3.12 o superior · Docker con Compose v2.
