First tagged version of the base. **It is not a final version**: it is a starting point for new projects while development continues, and it can change between `0.x` versions.

[Español](https://github.com/VictorDiazJauregui/django-saas-base/blob/v0.2.1/docs/releases/RELEASE-v0.1.0.es.md)

### Includes

- PostgreSQL 18 with Docker Compose, configured through variables so several projects can share the same machine.
- Django 5.2 LTS and Django REST Framework, with JWT authentication and request auditing.
- Admin panel with user management.
- Dependencies with `uv`, and `requirements.txt` for `pip`.
- Setup guide for Linux, WSL and Windows.

### Requirements

Python 3.12 or later · Docker with Compose v2.
